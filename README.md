# 🖥️ 감지기 생산현황 관리 시스템 (Detector PMS)

16:9 와이드 모니터 해상도에 최적화된 공정 생산 및 검정 관리 시스템입니다.
실시간 자동저장(Auto-Save), 일별 독립 데이터베이스, 마스터 동기화 및 엑셀(CSV) 내보내기를 지원합니다.

---

## 📌 주요 특징 및 기능 명세

### 1. 탭 1: [검정 일정] (공정검사 / 자동화조립 2단 분리)
* **기준 일자 (C2 셀)**: 검정예정일(DatePicker) 선택 시 해당 일자의 독립 저장된 데이터를 즉시 불러옵니다.
* **표 분리 구조**:
  * **상단 표: [공정검사]** - 공정별 품질 검사 및 일자별 생산 현황 관리
  * **하단 표: [자동화조립]** - 자동화 라인 조립 및 일자별 생산 현황 관리
* **작업일자 헤더 (F2:P2)**: 기준 일자로부터 +1일씩 자동 증가하여 11일간의 날짜를 계산 및 표출합니다.
  * **주말 시각화**: **토요일(파란색 테마)**, **일요일(빨간색 테마)** 자동 구분.
* **데이터 테이블**:
  * **품명**: [설정 탭]에 등록된 모든 품목이 두 표에 상시 노출됩니다.
  * **주간물량 (C열)**: 숫자만 직접 입력 가능 (문자 차단).
  * **생산완료 (D열)**: 동일 행 F~P열(11일간) 데이터의 합계가 실시간 자동 계산됩니다.
  * **잔량**: `주간물량 - 생산완료` 자동 계산 (0 달성 완료, 음수 초과 시각화 지원).
  * **일자별 생산량 (F~P열)**: 숫자 입력 시 즉시 생산완료/잔량이 연동되어 재계산되며 실시간 자동저장 및 1.5초 Toast 팝업 노출.
  * **하단 총계 요약행 및 상단 요약 뱃지**: 각 공정별 주간물량 총합, 총 생산완료, 총 잔량, 일자별 생산합계 자동 집계.
  * **CSV 내보내기**: 공정검사와 자동화조립 데이터가 명확히 분리된 한글 UTF-8 BOM CSV 파일로 즉시 다운로드.

### 2. 탭 2: [생산 일정]
* **기준 일자 (C2 셀)**: 생산일자(DatePicker) 선택 시 해당 일자 데이터 바인딩.
* **입력 테이블**:
  * **품명**: [설정 탭]에 등록된 품목 목록에서 드롭다운(Select)으로 선택.
  * **로트번호 (Lot No.)**:
    * **포맷 자동 유지**: 현재 연도 기준(예: 2026년 기준 `26-000` 형식 마스킹)으로 입력 지원.
    * **저장 규칙**: 연도가 바뀌어도 과거 기록이 변질되지 않도록 **텍스트(String) 고정값으로 영구 저장**.
  * **생산수량**: 숫자만 입력 가능 (문자 입력 방지).
  * **작업자별 작업시간 (E~M열)**:
    * [설정 탭]에 등록된 작업자 성명이 컬럼 헤더로 고정 노출 (동적 컬럼 지원).
    * 숫자 및 소수점 1자리(예: `7.5`, `8.0`)까지 입력 제어.
  * **생산 행 추가/삭제**: 버튼 하나로 간편하게 행 추가 및 이전 로트번호 자동 증가.
  * **하단 요약행**: 당일 총 생산수량 합계, 작업자별 총 작업시간 실시간 집계.

### 3. 탭 3: [설정] (마스터 데이터 관리)
* **품명 관리**: 신규 품목 추가, 인라인 수정, 삭제 기능 제공. [검정 일정]과 [생산 일정] 드롭다운에 실시간 동기화.
* **작업자 관리**: 작업자 이름 추가, 인라인 수정, 삭제 기능 제공. [생산 일정]의 컬럼 헤더에 실시간 동기화.

### 4. UI/UX 및 데이터 영속성
* **우측 상단 실시간 Toast**: 데이터 입력/수정 즉시 1.5초간 `"저장되었습니다"` 메시지 표시 후 부드럽게 퇴장.
* **16:9 와이드 디자인**: 테이블 컬럼 간격을 여유 있게 최적화하여 가로 스크롤 없이 시원한 대시보드 뷰 제공.
* **백업 및 복원**: 전체 시스템 JSON 백업/복원 및 한글 엑셀 깨짐 없는 UTF-8 BOM CSV 내보내기 지원.

## 🚀 구동 방법

### 방법 1. 원클릭 실행 (추천)
`c:\AiProject\start.bat` 파일을 더블클릭하면 Windows 내장 초경량 로컬 웹 서버가 실행되고 브라우저가 자동으로 열립니다.

### 방법 2. 직접 열기
`c:\AiProject\index.html` 파일을 브라우저(Chrome, Edge 등)로 직접 더블클릭하여 열어도 모든 기능이 100% 정상 작동합니다.

### 방법 3. PowerShell 명령어 실행
```powershell
cd c:\AiProject
powershell -ExecutionPolicy Bypass -File .\start_server.ps1
```
