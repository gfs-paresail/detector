# 🖥️ 감지기 생산현황 관리 시스템 (Detector PMS v4.0)

Google Firebase Cloud Firestore 연동 및 로컬스토리지 자동 임시저장 기반의 공정 생산, 검정 일정 및 작업시간 통합 관리 시스템입니다.

---

## 📌 주요 특징 및 기능 명세

### 1. 탭 1: [생산현황]
* **검정예정일 및 생산 시작일 듀얼 날짜 체계**:
  * 생산 시작일과 함께 **검정예정일** 날짜 선택기를 지원합니다.
* **좌측 일정 사이드바 (연도/월 필터 & 최근순 정렬)**:
  * **[일정저장]** 버튼을 누르면 해당 검정예정일(예: `2026-11-05`) 명칭으로 일정이 등록됩니다.
  * 사이드바 상단에서 **연도별**, **월별(전체, 1~12월)** 로 저장된 일정을 간편하게 검색할 수 있습니다.
  * 최근 저장된 일자가 최상단에 오도록 자동 내림차순 정렬되며, 일자가 많아지면 세로 스크롤바가 제공됩니다.
  * 사이드바의 날짜 버튼을 클릭하면 저장되었던 전체 생산현황 데이터가 즉시 로드됩니다.
* **기본 10일간 표시 및 동적 확장 [ + ] 버튼**:
  * 작업 일정을 기본 10일간 표시하며, 10일차 마지막 칸 옆 **`+` 버튼**을 누르면 1일씩 열이 무제한 확장됩니다.
* **테이블 좌측 고정 (Sticky Column) & 가로 스크롤**:
  * `NO`, `품명`, `주간물량`, `생산완료`, `잔량` 5개 열은 화면 좌측에 항상 고정되며, 날짜 열 부분만 가로 스크롤됩니다.
* **잔량 헤더 색상 표준화**:
  * 헤더의 '잔량' 글자색은 다른 헤더와 동일하게 표시되며, 미달성 잔량 '숫자'만 선명한 적색(Red)으로 강조됩니다.
* **2단 분할 테이블**:
  * **상단 표: [공정검사]** / **하단 표: [자동화조립]**
* **주말 잠금**:
  * 토요일(파랑), 일요일(빨강) 열은 슬림화되어 데이터 입력이 차단됩니다.

---

### 2. 탭 2: [생산 일정]
* **3개 공정 표 분할 ("조립", "검사", "기타")**:
  * 독립적인 3개의 표 카드로 분할되어 공정별 생산량과 작업시간을 정밀하게 기록합니다.
* **마스터 품목 순서 상시 고정 표시**:
  * [조립] / [검사]: 설정의 [품목등록] 순서대로 행이 항상 고정 표시됩니다.
  * [기타]: 설정의 [기타작업 등록] 순서대로 행이 항상 고정 표시됩니다.
* **작업자 고정 vs 변동 체계**:
  * **고정 작업자**: 표 헤더에 항상 고정 컬럼으로 노출되어 작업시간을 즉시 입력할 수 있습니다.
  * **변동 작업자**: 화면 상단의 `변동 작업자 투입` 드롭다운에서 선택하여 해당 일자에만 투입·배치할 수 있습니다.
  * 일자별로 투입된 작업자와 작업시간, 생산수량, 로트번호, 비고가 독립적으로 저장됩니다.
* **스마트 로트번호 자동완성**:
  * 숫자만 입력하면 (예: `1`) 현재 연도를 반영한 **`26-001`** 포맷으로 자동 변환됩니다.

---

### 3. 탭 3: [설정] (마스터 데이터 관리)
* **3개 관리 카드 구조**:
  1. **[품목등록]**: [생산현황] 및 [생산일정 - 조립, 검사] 공통 품목
  2. **[기타작업 등록]**: [생산일정 - 기타] 표 전용 항목
  3. **[작업자 관리]**: 작업자 성명 및 [고정 / 변동] 구분 드롭다운
* **마우스 드래그 & 드롭 (Drag & Drop) 순서 변경**:
  * 등록된 항목 좌측의 핸들을 잡고 끌어당겨 위/아래 순서를 자유롭게 조정할 수 있으며, 생산현황 및 생산일정 표에도 즉시 반영됩니다.
* **[설정 저장] 버튼**:
  * 품목 순서 및 작업자 설정을 클릭 한 번으로 DB에 영구 저장합니다.

---

### 4. Firestore 무료 플랜 최적화 및 공통 편의 기능
* **Firestore 읽기/쓰기 99% 절감**:
  * 키 입력마다 발생하는 실시간 자동 쓰기를 완전 차단하고, **[일정저장] / [설정 저장] 버튼을 누를 때만 Firestore DB 서버에 단건 저장**합니다.
  * 브라우저 로컬 스토리지 자동 임시저장 (`Auto-Save to LocalStorage`)으로 작업 중 데이터 유실을 방지합니다.
* **이탈 방지 경고 (`beforeunload`)**:
  * 저장하지 않은 변경사항이 있는 상태에서 페이지를 닫거나 새로고침, 다른 날짜로 이동하려 하면 경고 팝업으로 저장을 유도합니다.
* **클릭 시 기존 값 즉시 덮어쓰기 (자동 전체 선택)**:
  * 셀을 클릭하거나 Tab/Enter로 포커스할 때 기존 값이 전체 블록 선택되어, 값을 지우지 않고 새 숫자를 누르는 즉시 깨끗하게 교체됩니다.
* **합계 숫자 우측 정렬**:
  * 테이블 하단의 모든 합계 숫자 셀이 우측 정렬되어 자릿수 시인성이 대폭 향상되었습니다.
* **헤더 DB 상태 표시**:
  * `DB 연결됨` (녹색 인디케이터)으로 간소화 및 직관적 표시.
